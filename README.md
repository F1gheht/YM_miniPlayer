# YM Mini — мини-плеер для Яндекс Музыки

Маленькое всплывающее окно для десктопной Яндекс Музыки (Windows 10/11):
обложка, название и исполнитель, ⏮ ⏯ ⏭, полоса перемотки трека и громкость.
Окно появляется по горячей клавише или кнопке мыши поверх всех окон и **не забирает фокус**:
можно нажать паузу посреди игры или набора текста, курсор останется там, где был.

## Как это работает

Программа не изменяет файлы Яндекс Музыки, поэтому не ломается при её обновлениях.

* **Трек, кнопки и перемотка** — через системные медиа-контролы Windows (SMTC), куда Яндекс Музыка
  сама передаёт текущий трек (это то же, что показывает всплывашка громкости Windows).
* **Громкость** — громкость приложения «Яндекс Музыка» в микшере Windows
  (общая громкость системы не меняется).

## Установка

1. Скачайте `YMMini-Setup.exe` (на GitHub — во вкладке **Releases**) и запустите его.
   Права администратора не нужны, Python тоже.
2. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите
   **Подробнее → Выполнить в любом случае**. Так бывает с любой программой без цифровой подписи.
3. Всё. YM Mini запускается вместе с Windows и незаметно ждёт в фоне. Когда открыта
   Яндекс Музыка, окно плеера открывается по **Ctrl+Alt+M**.

Удалить: «Параметры → Приложения» или «Пуск → Удалить YM Mini».
Настройки остаются в `%APPDATA%\YMMini` — удалите папку, если они больше не нужны.

## Управление

* **Перемотка** — полоса над громкостью: клик в любое место или перетаскивание.
  Пока тянете, слева видно время, на которое перемотаете.
* **Громкость** — нижний ползунок или колесо мыши над окном. Клик по динамику — без звука.
* Окно можно перетащить за фон, позиция запоминается.
* Кнопка **⋯** в окне или правый клик по окну → **Настройки…**, «Выход».
  Значок в трее можно включить в настройках.

## Кнопки «Нравится», «Перемешать», «Повтор»

* ♥ справа от названия — добавить трек в «Мне нравится». Если трек уже там, сердце красное,
  и повторное нажатие убирает лайк.
* ⇄ слева от ⏮ — перемешать, ↻ справа от ⏭ — повтор. Нажатие работает так же, как
  кнопка в самой Яндекс Музыке (повтор переключается по кругу, как в приложении).
* В «Моей волне» перемешивания и повтора нет, поэтому там эти кнопки неактивны.

Эти кнопки работают через порт управления Яндекс Музыки. Когда вы её открываете, YM Mini
за секунду перезапускает её с этим портом — окно мигнёт один раз. Если Яндекс Музыка уже была
открыта до запуска YM Mini, нажмите **⋯ → «Перезапустить Яндекс Музыку…»**.

Порт открыт только для программ на этом компьютере (сайты в браузере к нему не подключатся),
но любая запущенная у вас программа сможет управлять Яндекс Музыкой, пока она открыта.
Отключить: в настройках снимите галочку «Кнопки «Нравится», «Перемешать», «Повтор»».

## Сочетания: клавиатура и мышь

В настройках кликните по полю действия и нажмите то, что хотите назначить:

* клавиши: `Ctrl + Alt + M`, `F9`, медиаклавиши;
* кнопки мыши: `Мышь 4`, `Мышь 5`, клик колесом;
* клавиши + мышь: `Ctrl + Мышь 4`, `Alt + Колесо ↑`, `Shift + ЛКМ`, даже `Z + Мышь 5`.

ЛКМ, ПКМ и прокрутку колесом можно назначить только вместе с клавишей, иначе
перестанут работать обычные клики и прокрутка. Назначенное нажатие мыши не уходит в другие
программы — например, `Мышь 4` не будет листать браузер назад.

Можно назначить: показ окна, паузу, следующий/предыдущий трек, перемотку вперёд/назад
(шаг настраивается), громкость ±, «Нравится», «Перемешать» и «Повтор». Esc в поле — отмена записи, ✕ — убрать сочетание.

## Запуск вместе с Яндекс Музыкой

Включено по умолчанию: установщик добавляет YM Mini в автозагрузку Windows,
и он ждёт в фоне без горячих клавиш. Как только вы открываете Яндекс Музыку,
начинают работать горячие клавиши (само окно не всплывает — только по Ctrl+Alt+M). Когда закрываете — плеер снова уходит в фон.

Выключить можно в настройках (галочки «Запускаться вместе с Яндекс Музыкой» и
«Показывать окно, когда Яндекс Музыка запускается») или снять «Запускать вместе с Windows» в меню **⋯**.
Если нужно открыть настройки при закрытой Яндекс Музыке, запустите YM Mini из меню «Пуск» — появится окно.

Настройки хранятся в `%APPDATA%\YMMini\settings.json`.

## Если что-то не работает

* **«Яндекс Музыка не найдена»** — приложение не запущено или ещё ничего не играло.
  Включите трек. Можно включить в настройках «управлять текущим плеером Windows».
* **Полоса перемотки серая** — приложение не сообщило Windows длительность трека
  или не разрешает перематывать его.
* **Ползунок громкости серый** — у Windows пока нет аудиосессии приложения.
  Она появляется после начала воспроизведения.
* **«Не удалось назначить сочетание»** — его уже заняла другая программа. Выберите другое.

## Для разработчиков

* `run.bat` — запустить из исходников (поставит Python и зависимости, если их нет).
* `debug.bat` — то же, но с консолью: видно ошибки.
* `build.bat` — собрать установщик `Output\YMMini-Setup.exe` (PyInstaller + Inno Setup;
  Inno Setup поставится через winget, если его нет). Версия берётся из файла `VERSION`.
* GitHub сам собирает установщик (`.github/workflows/build.yml`): после каждого пуша в `main`
  он лежит во вкладке **Actions** → нужный запуск → **Artifacts**. Чтобы выпустить релиз,
  создайте тег, например `git tag v1.0.0 && git push --tags` — установщик появится в **Releases**.
